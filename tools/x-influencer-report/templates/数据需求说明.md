# 推广合作数据需求（可直接转发）

您好，我们正在评估和您的推广合作，想请您协助提供以下数据，只用于内部评估，不会对外公开。附件是填写模板（KOL数据模板.xlsx），最省事的方式见第 1 项。

## 必需

1. **近 12 个月的推文数据**
   - 最简单：X 网页版 → Analytics（数据分析）→ Content（内容）→ 时间选近 1 年 → Export data（导出），把导出的 CSV 直接发给我们即可。
   - 导出不了的话，按模板「推文明细」表填写，至少包括：帖子链接、发布时间、类型、正文、浏览量、点赞、转推、评论。

2. **近 3 个月的商业合作帖**（模板「广告案例」表）
   - 每条合作帖的日期、品牌、链接、合作形式、浏览量；如果有链接点击数、品牌方反馈的注册/开户数，也请一并提供。
   - 请注明是否有排他约定（尤其是交易平台类）。

3. **粉丝画像**（模板「粉丝画像」表，或 X 后台 Audience 页截图）
   - 最重要的是**粉丝地区分布 Top 10**，其次是语言、性别、年龄。

## 选填（有的话会加快推进）

4. **账号概况**：当前粉丝数、12 个月前粉丝数、近 28 天 / 90 天总曝光和互动率（Analytics 总览页截图即可）。
5. **报价与档期**：各合作形式的报价、是否可以带追踪链接、是否接受外汇 / 差价合约品牌、最早档期。

谢谢！
